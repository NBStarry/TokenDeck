- 用户希望在 GitHub 展示产品界面和本机真实用量。复用 Svelte 卡片，新增独立静态预览入口，不调用 Tauri 或远程操作 CLI。

- 页面明确快照时间、过期状态和刷新含义；复用已有暗色卡片，支持宽屏与手机浏览。本轮不扩展 OpenRouter 展示。
